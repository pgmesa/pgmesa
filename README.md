### What I'm working on
- 🔥 [Raxis](https://github.com/pgmesa/raxis): PyTorch's core (tensors, autograd, CPU and CUDA kernels) rebuilt from scratch in C++20, to understand how it works inside.
- ✍️ [Rebuilding PyTorch](https://blog.pgmesa.com/series/rebuilding-pytorch/): the series on my blog where I explain it, one piece at a time.
